# Exemplos de Redes Neurais

Este repositório contém exemplos de implementações de redes neurais utilizando diferentes arquiteturas. Todos os exemplos utilizam como base o projeto PyTorch.

Este repositório está organizado em diferentes diretórios, cada um contendo exemplos de uma arquitetura específica de rede neural.

Diretórios:
- `mlp`: Exemplos de redes neurais feedforward.
- `convolutional`: Exemplos de redes neurais convolucionais.
- `recurrent`: Exemplos de redes neurais recorrentes.

Cada diretório contém exemplos de código, arquivos de configuração e instruções para executar os exemplos correspondentes.
